# airport-sim

Starter project for an airport simulator using Vite + TypeScript + Three.js.

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

Then open the local URL shown by Vite to see the 3D scene.

## Validation

```bash
pnpm typecheck
pnpm lint
pnpm test
```

## Current scope

This project currently contains only a base Three.js scene with:
- a green ground plane
- orbit controls

No airport-specific features are included yet.
